How a neural network learns

Every model on this site is the same machine underneath. The vision networks, the Rocket League agent, the thing that writes sentences: all of them are a stack of multiplications with a knob on each one, plus a procedure for turning the knobs. This page is that machine, small enough to watch work. Draw some points and train it in front of you.

The whole idea in four sentences

A neural network is a function with adjustable numbers in it. You feed in an input, here the two coordinates of a point, and it produces an output, here a number between 0 and 1 meaning "how confident am I that this one is orange?".

A loss function scores how wrong that answer was. Backpropagation then works out, for every weight in the network, whether nudging it up or down would have made the loss smaller, and by how much. Gradient descent takes a small step that way. Run that a few thousand times and the boundary below bends itself around your data.

loss  =  how wrong we were   →   gradient  =  ∂loss/∂weight   →   weight  ←  weight  −  learning-rate × gradient

That's the whole thing. Everything else in deep learning is this loop with better plumbing attached.

Training

Watch the two curves separate

While both curves fall, the network is learning something real. The moment the orange test curve turns back upward while the blue one keeps dropping, it has switched to memorising noise. That's overfitting, and it's the most common way a model that looks great turns out to be worthless.

What each neuron is actually doing

Each tile below is one hidden neuron, drawn across the same square of space as the main canvas: orange where it fires positively, blue where it fires negatively. Neurons in the first layer can only draw a straight edge, because a weighted sum followed by a squashing function has no other move available to it.

The second layer is where it gets interesting. Its neurons combine those straight edges into corners, stripes and blobs. That's all depth is: composing simple pieces into complicated shapes. Train the spiral with one hidden layer, then with three, and compare the tiles.

Experiments worth running

  • Remove all hidden layers. The model collapses into logistic regression and can draw exactly one straight line. On the blobs it does fine. On the spiral it's hopeless however long you train it, because some problems need depth rather than patience.
  • Train the spiral with 2 neurons per layer, then 16. Capacity is how complicated a shape the model can represent. Too little and it can't fit the data. Too much and it fits your noise with the same enthusiasm as your signal.
  • Set noise to 0.35 and train a big network for a long time. Train accuracy marches toward 100% while test accuracy stalls or slides backward. Now switch weight decay on and watch the boundary calm down.
  • Set the learning rate to 0.3. The loss curve turns into a saw blade. The steps are big enough to overshoot the valley they're trying to get into, every time.
  • Switch tanh to ReLU on the circles. ReLU boundaries are built from straight facets and you can count the polygon's sides. tanh gives you curves. The activation function is quite literally the shape of what the network is able to draw.
  • Draw a tiny cluster of orange points inside the blue region. Then train and see how far that one contradiction bends the whole boundary. That's how brittle a model built on a handful of points really is.
