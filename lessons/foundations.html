How a neural network learns

Every model on this site — the vision networks, the Rocket League agent — is the same machine underneath: a stack of multiplications with a knob on each one, and a procedure for turning those knobs. This page is that machine, small enough to watch. Draw some points and train it in front of you.

The whole idea in four sentences

A neural network is a function with adjustable numbers in it. You feed in an input — here, the two coordinates of a point — and it produces an output, here a number between 0 and 1 meaning "how confident am I that this point is orange?".

A loss function scores how wrong that output was. Backpropagation then works out, for every single weight in the network, whether nudging it up or down would have made the loss smaller — and by how much. Gradient descent takes a small step in that direction. Repeat a few thousand times and the boundary you see below bends itself around your data.

loss  =  how wrong we were   →   gradient  =  ∂loss/∂weight   →   weight  ←  weight  −  learning-rate × gradient

That's it. Everything else in deep learning is this loop with better plumbing.

Training

Watch the two curves separate

While both fall, the network is learning something real. The moment the orange test curve turns back upward while the blue one keeps dropping, it has started memorising noise instead of finding structure. That's overfitting, and it is the single most common way a model that looks great turns out to be useless.

The loss landscape

Two random directions through the network's entire weight space, swept across a grid and coloured by the training loss found there — bright is low, dark is high. The white line is the path training has actually taken, projected onto that plane, and the dot is where the model is now. It is a two-dimensional window onto a 67-dimensional surface, so treat it as a cross-section rather than a map: the real descent happens in every direction at once, and this slice is recomputed as the other weights move.

What each neuron is actually doing

Each tile below is one hidden neuron, drawn across the same square of space as the main canvas: orange where that neuron fires positively, blue where it fires negatively.

Neurons in the first layer can only ever draw a straight edge — that's all a weighted sum followed by a squashing function can do. The interesting part is the second layer, whose neurons combine those straight edges into corners, stripes and blobs. Depth is exactly this: composing simple pieces into complicated shapes. Train the spiral with one hidden layer, then with three, and compare the tiles.

Experiments worth running

  • Remove all hidden layers. The model collapses to logistic regression and can only draw one straight line. On the blobs it does fine. On the spiral it is hopeless, no matter how long you train — some problems need depth, not patience.
  • Train the spiral with 2 neurons per layer, then 16. Capacity is the ability to represent complicated shapes. Too little and it can't fit; too much and it fits your noise as eagerly as your signal.
  • Set noise to 0.35 and train a big network for a long time. Watch train accuracy march toward 100% while test accuracy stalls or falls. Now add weight decay and watch the boundary calm down.
  • Set the learning rate to 0.3. The loss curve turns into a saw. The steps are so big they overshoot the valley they're trying to descend into.
  • Switch tanh to ReLU on the circles. ReLU boundaries are made of straight facets — you can see the polygon. tanh gives you curves. The activation function is quite literally the shape of what the network can draw.
  • Draw a tiny cluster of orange points inside the blue region. Then train. How much does one small contradiction distort the whole boundary? That's how brittle a model trained on a handful of points really is.
