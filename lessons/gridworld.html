Reinforcement learning from zero

Before a neural network drives a car, understand the idea underneath it with something you can see all of at once. Here an agent knows nothing about the maze you draw. It bumps into walls, falls into pits, and slowly fills in a number for every move in every square — until a route appears that nobody told it about.

The setup: states, actions, rewards

Reinforcement learning always starts with the same four things, and it's worth naming them concretely before any maths shows up:

State

Which square the agent is standing on. 88 of them here.

Action

Up, right, down or left. Four choices, every step.

Reward

+1 for the goal, −1 for a pit, and a small cost for every step taken.

Policy

The rule it follows: which action to pick in each state. This is what gets learned.

The agent's memory is a table called Q. For each square and each of the four directions it holds one number: if I take this move here and act sensibly afterwards, how much total reward should I expect? Every square in the grid below is drawn as four triangles — one per direction — shaded by that number. Green is promising, red is regret.

Progress

Steps per episode is the clearest sign of learning: it starts in the hundreds — pure wandering — and drops toward the length of the shortest safe route.

The one equation

Every single step the agent takes runs this update, and nothing else. It is the whole algorithm:

Q(s,a)  ←  Q(s,a)  +  α [ r + γ maxa′ Q(s′,a′) − Q(s,a) ]

Read it as a correction. The green part is a fresh estimate of what that move was worth: the reward you just got, plus the discounted value of the best move available from wherever you landed. The blue part is what you believed before. The difference between them — the temporal-difference error — is the surprise, and α decides what fraction of the surprise you take on board.

The clever bit is maxa′. The agent bootstraps: it improves its guess using another of its own guesses. Early on those guesses are all zero and nothing seems to happen — until the first time it stumbles into the goal. That single +1 gets carried one square backwards per visit, and if you run at "Step by step" right after a success you can watch the value spread back down the corridor.

Race it yourself

Press Race the agent and walk the maze with the arrow keys. You will almost certainly win, and the interesting part is why: you can see the whole grid at once and you already know what a pit is. The agent gets one square of feedback at a time and had to discover that pits are bad by falling in them. Every RL result you read about is a system solving a problem under that handicap.

Exploration versus exploitation

With ε = 0 the agent always takes the move it currently believes is best. That sounds smart and is often fatal: the first mediocre route it finds becomes the only route it will ever consider, because it never tries anything else long enough to learn better. With ε = 1 it wanders forever and learns a great Q-table it never actually uses. Every RL algorithm ever written is some answer to this tension — including the entropy bonus in the Rocket League lesson.

Hyperparameters

Experiments worth running

  • The cliff. Load "Cliff walk". The fast route runs along the edge of a row of pits; the safe route goes the long way around. Now raise ε to 0.4 and watch the agent deliberately avoid the edge — with random moves in the mix, walking next to a cliff genuinely is worse. It isn't being timid; it's being correct about the world it lives in.
  • Turn off the step cost. Set it to 0.000. The agent still reaches the goal, but it stops caring how long it takes, and the arrows go from a clean route to an aimless drift. Cost of time is what makes a policy efficient.
  • Make the floor slippery. At 40% slip, actions only mostly work. Watch the values near pits go deeply negative — the agent learns to keep a safety margin, which is exactly what you'd want a robot to do.
  • Drop γ to 0.6. Distant rewards get discounted into irrelevance. In a long maze the agent can no longer see far enough ahead to bother.
  • Move the goal mid-run. Draw a new goal somewhere else while it's running. The old values are now lies, and it takes real time to unlearn them — a small taste of why changing environments are hard.
Where this stops working

The Q-table has one row per state. That's fine for 88 squares. A Rocket League arena has continuous positions, velocities and angles — an infinite number of states, no two ever visited twice. The next lesson replaces the table with a neural network that generalises across states it has never seen, which is precisely what deep reinforcement learning is.
