Learn machine learning by building it

Eight lessons and a capstone, all of them running on your own machine while you watch. You write the reward function for a Rocket League bot, and it does exactly what that function says, which is rarely what you meant. You draw a track, sixty cars evolve their way around it, and the survivor beats you in a race. By the last lesson you're feeding a page of your own writing to a transformer and watching it learn to spell.

Everything runs here

No API keys, no downloads, nothing phoning home. Backpropagation, Adam, PPO, convolutions and attention are all plain JavaScript sitting in this repository, and your laptop fan is what does the training.

Skip the queue, or don't

Finished models ship with the site, so the digit recogniser works the second the page loads and you can scrub a whole Rocket League run like a video. There's a button on every one of them that throws the finished weights away and starts from noise, if you'd rather sit through it. Plenty of people should.

Badges you have to earn

Twenty-nine of them, and none are for clicking around. They fire when a model of yours actually does the thing: a car that finishes a lap, a bot that scores on an empty net, a transformer that produces a real word. You can't collect them by scrolling.

You're meant to break it

Every lesson ends with a list of ways to sabotage the thing you just built: reward hacking, overfitting, exploration that dies, a learning rate set high enough to blow the whole run apart. Watching a model fail on purpose teaches more than watching it succeed by accident.

Where to start

In order is best; each lesson leans on the one before it. But most people arrive wanting one specific thing, so:

  • "I want the Rocket League bot." Just go. The timelapse near the top replays an entire training run in about thirty seconds, so you'll know within a minute whether you want the rest. If reward, policy and discount are new words, spend twenty minutes in Q-learning first and the whole page will land differently.
  • "I just want to play with something." Evolve a driver assumes nothing. Sixty cars, no teacher, and a track you draw. They're hopeless for about ten generations.
  • "I want to understand vision models." Convolutions, then Train a CNN, then Vision Transformers. You start by doing the multiplication by hand on a 3×3 grid and finish inside a real transformer with its attention maps pulled open.
  • "I want to understand language models." Do Vision Transformers first — it's easier to see attention working on a picture than on text. Then Teach a model to write is the identical block with characters swapped in for patches and a mask that stops it reading ahead.
  • "I've never trained anything." Foundations. Every other lesson on this site is that same loop wearing a costume.

Running it yourself

Every page is static HTML, CSS and JavaScript. No build step, no dependencies, no node_modules. Double-clicking index.html works, though serving the folder works better (the Rocket League lesson can use a background thread that way): 

git clone https://github.com/ZBelohlavek/MachineLearning.git
cd MachineLearning
python3 -m http.server 8000     # then open http://localhost:8000

The learning code lives in assets/js/lib/ and is meant to be read: nn.js has dense layers, backpropagation and Adam, cnn.js has convolution and pooling, vit.js has attention and layer norm. Environments sit under assets/js/lessons/. Every backward pass in there is written out by hand and checked against numerical gradients by tests/gradcheck.cjs. If you've only ever called loss.backward() and taken it on faith, that's the file to open.
