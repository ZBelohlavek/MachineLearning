Learn machine learning by building it

Eight lessons and a capstone, each one a working model you train yourself in the browser. Design the reward function for a Rocket League bot and watch it teach itself to score. Evolve a population of cars around a track you drew, then race the winner. Train a tiny language model on your own writing and watch noise turn into sentences.

Everything runs here

No servers, no API keys, no downloads. Backpropagation, Adam, PPO, convolutions, attention and a causal transformer are all plain JavaScript in this repository, and your machine does the training.

Skip the waiting, or don't

Trained models ship with the site, so the digit recogniser works the instant you open it and the Rocket League run replays as a timelapse you can scrub. One button throws them away for the full from-scratch version.

Goals, challenges and quizzes

Twenty-nine badges, none for clicking around: they unlock when a model of yours does something — evolves a car that finishes, trains a bot that scores, teaches itself to write words, or answers three questions about what you just watched happen.

You are meant to break it

Every lesson ends with experiments designed to make the model fail in an instructive way — reward hacking, overfitting, dead exploration, learning rates that explode.

Where to start

If you're new to all of this, go in order — the lessons deliberately build on each other. If you came for one thing, jump straight to it:

  • "I want the Rocket League bot." Go there directly — the timelapse at the top shows the whole training run in half a minute. If the words reward, policy and discount are new, the Q-learning lesson first is twenty well-spent minutes.
  • "I just want to play with something." Evolve a driver needs no background at all: watch sixty cars fail, then get good, then beat you in a race.
  • "I want to understand vision models." Convolutions → Train a CNN → Vision Transformers, in that order. The first is arithmetic you do by hand; the last is a real transformer with its attention maps exposed.
  • "I want to understand language models." Vision Transformers first for the attention mechanism, then Teach a model to write, which is the same block with causal masking and characters instead of patches.
  • "I've never trained anything." Start with Foundations. Everything else is that same loop with more interesting shapes attached.

Running it yourself

Every page is static HTML, CSS and JavaScript with no build step and no dependencies. Open index.html straight from disk and it works, or serve the folder if you prefer: 

git clone https://github.com/ZBelohlavek/MachineLearning.git
cd MachineLearning
python3 -m http.server 8000     # then open http://localhost:8000

The machine learning code is deliberately readable and lives in assets/js/lib/: nn.js (dense layers, backpropagation, Adam), cnn.js (convolution, pooling), vit.js (attention, layer norm) and the per-lesson environments under assets/js/lessons/. The backward passes are written out by hand and checked against numerical gradients — if you've only ever called loss.backward(), they're worth a read.
